# Bibliographic data source

The current ISBN lookup and imported covers use openBD, as described in
[openBD usage](OpenBD_Usage.md). The NDL-only lookup described during development
on 2026-10-13 is not the current provider contract. This document retains the NDL
source/attribution conditions relevant to NDL-derived metadata; it must not be
read as an instruction to replace the current openBD integration.

- API specification: https://ndlsearch.ndl.go.jp/help/api/specifications
- Provider and metadata reuse conditions: https://ndlsearch.ndl.go.jp/help/api/provider
- NDL API use and credit instructions: https://ndlsearch.ndl.go.jp/help/api
- Bibliographic data attribution and modification guidance: https://www.ndl.go.jp/data/data_service/quickguide
- NDL content terms and third-party content exceptions: https://www.ndl.go.jp/sitepolicy/terms

NDL-created bibliography data may be used without a separate application, including for commercial use. Its stated reuse conditions are compatible with CC BY 4.0. The API requires a visible indication that the application uses NDL Search. NDL asks users to identify NDL as the source, indicate when its records have been modified, and avoid concurrent or excessive requests. Operators making ongoing API requests are asked to provide contact and usage information through the NDL API form. The current application presents openBD source credit and imported-record details, including upstream attribution where applicable. See [openBD usage](OpenBD_Usage.md) and the README for the current provider behavior.

Changes to the data provider, retrieval fields, deployment pattern, or use of cover images require a new conditions review before release.
