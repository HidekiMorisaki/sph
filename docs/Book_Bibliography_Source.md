# Bibliographic data source

Checked 2026-10-13. The book lookup uses only the National Diet Library Search OpenSearch API with data provider `iss-ndl-opac-national` (National Bibliography). It does not retrieve images or records from other providers.

- API specification: https://ndlsearch.ndl.go.jp/help/api/specifications
- Provider and metadata reuse conditions: https://ndlsearch.ndl.go.jp/help/api/provider
- NDL API use and credit instructions: https://ndlsearch.ndl.go.jp/help/api
- Bibliographic data attribution and modification guidance: https://www.ndl.go.jp/data/data_service/quickguide
- NDL content terms and third-party content exceptions: https://www.ndl.go.jp/sitepolicy/terms

NDL-created bibliography data may be used without a separate application, including for commercial use. Its stated reuse conditions are compatible with CC BY 4.0. The API requires a visible indication that the application uses NDL Search. NDL asks users to identify NDL as the source, indicate when its records have been modified, and avoid concurrent or excessive requests. Operators making ongoing API requests are asked to provide contact and usage information through the NDL API form. The application presents source credit on the book page and source details on imported book records; its README files carry the source and use details.

Changes to the data provider, retrieval fields, deployment pattern, or use of cover images require a new conditions review before release.
