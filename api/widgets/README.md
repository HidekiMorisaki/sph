# SPH declarative widget catalogue (contract 1)

`catalogue.json` is the standalone official catalogue, distributed with SPH under
the repository MIT license. Copy this directory and the root LICENSE when reusing
these definitions. It contains no employee data or executable widget code.

Companies can publish their own JSON catalogue at a public HTTPS URL, then register
it in **System settings → Widgets**. See [the authoring and API contract](../../docs/Widgets.md).
External definitions are not automatically installed, approved, or updated.
